01The start
It started with a broken layout.

I started coding in my first year of college. A simple HTML page for a class activity took me a whole weekend because I kept breaking the layout. It was frustrating, but when it finally worked I wanted to build more. From there I moved to JavaScript, then databases, then full-stack apps.

02The bug
Two days on the wrong thing.

The hardest bug I've had was in our capstone: data saved fine but never showed up on the next page. I spent two days checking the screen before I found the problem was in my database query. Now I read the error and check the data first, before touching the UI.
